== Purpose

An example link:{uri-jenkins-shared-library-docs}[Jenkins Pipeline Shared Library] built with the link:{uri-shared-library-plugin}[Shared Library Gradle Plugin].

Use this as a reference for:

* Structuring a shared library project (`src/`, `vars/`, `resources/`)
* Writing JPU unit tests (`test/unit/`) in Groovy, Java, or Kotlin
* Writing `JenkinsRule` integration tests (`test/integration/`) with sandbox enabled
* Wiring the plugin with a Jenkins BOM and additional plugins

== Running

[source,shell]
----
./gradlew build          # compile + unit tests
./gradlew integrationTest  # JenkinsRule tests (downloads Jenkins WAR on first run)
./gradlew check          # both
----
